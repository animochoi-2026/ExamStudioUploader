# 문제공방 시험지 업로더

시험지를 여러 개 넣고 업로드 버튼을 누르면 문항 인식·풀이·난이도 평가·문제공방 등록을 진행하는 Windows 앱입니다.

[최신 버전 다운로드](https://github.com/animochoi-2026/ExamStudioUploader/releases/latest)

1. Release의 `ExamStudioUploader-버전-win32-x64.zip`을 내려받아 압축을 모두 풉니다.
2. `문제공방 시험지 업로더.exe`를 실행합니다. 폴더 안의 파일을 함께 보관하세요.
3. 계정·설정에서 본인의 문제공방 계정과 ChatGPT 또는 Claude 구독에 로그인합니다. 문제공방 자료실의 가입·업로드 권한이 필요합니다.
4. PDF 또는 이미지를 끌어놓고 학교·학년 등 누락된 정보를 채운 다음 **업로드 시작**을 누릅니다.
5. 완료된 문항은 문제공방 웹에서 확인하고 검수합니다. 확인이 필요한 항목은 앱에 사유가 표시됩니다.

원본 파일은 이동·삭제하지 않습니다. 작업 기록은 `%APPDATA%/ExamStudioUploader`에 보관됩니다. 다른 PC의 미완료 작업이나 로컬 로그는 자동으로 관리자에게 전송되지 않습니다.

실행 시 GitHub 새 버전을 확인합니다. 업데이트 버튼을 누르면 크기·체크섬을 검증하여 프로그램을 교체하고 사용자 자료는 보존합니다.

각자의 구독 이용 한도가 적용됩니다. AI 처리 결과는 웹에서 검수해 주세요. 이 저장소는 프로그램 배포와 사용 안내를 제공합니다.
